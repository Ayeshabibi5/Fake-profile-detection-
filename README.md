Fake Profile Detection

Project Overview

This project is my Final Year Project (FYP) for the BS Information Technology degree. It focuses on detecting potentially fake or suspicious social media profiles, particularly on Instagram.

Objective

The main objective is to help identify suspicious profiles by analyzing profile information and selected features.

Technologies

- Programming Language: Python
- Machine Learning: Scikit-learn
- Backend: Flask
- Frontend: HTML, CSS, JavaScript
- Database: SQLite
- Development Tool: Visual Studio Code

Project Goal

The goal is to develop a simple web-based system that analyzes profile details and helps users identify potentially fake profiles.
